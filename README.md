# Gitバージョン管理・PR演習

## プロジェクト概要
学生成績管理システム（`StudentGradeManager`）を作成し、  
Gitによるバージョン管理とGitHubのPull Request / Issue操作を練習しました。

## 実装機能
- 生徒情報の追加（入力検証付き）
- 個人・クラス平均点計算
- CSVエクスポート機能
- 詳細なdocstringとコメント

## ファイル構成
- `student_manager.py` ← メインクラス
- `.gitignore`
- `README.md`

## 実行方法
```bash
python student_manager.py
